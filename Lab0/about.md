- Что такое Git и для чего он используется?

  Git — это система контроля версий. Она нужна для отслеживания изменений в коде, чтобы можно было вернуться к старым версиям и работать в команде.


- В чём разница между централизованными и распределёнными системами контроля версий?

  В централизованных (SVN) есть один главный сервер. В распределённых (Git) у каждого разработчика есть полная копия проекта.


- Что такое репозиторий в Git?

  Это хранилище проекта, где лежат все файлы и история их изменений.
